# 教材处理与答题交接格式

状态：核对标准与完整流程验收已于 2026-10-05 经用户确认；后续规格和任务使用本地 Markdown。本文约定三个能力的交接；实际操作见 pipeline-usage.md，验收见 questions/pipeline-acceptance.md。

## 已确定的范围

- `pdfs`：PDF → 页面图 → OCR/文本 → 对照核对。
- `daofa-build`：教材内容 → 知识点 → Markdown → 页码来源 → 题眼索引。
- `daofa-qa`：题目 → 检索知识库 → 材料分析 → 参考答案。
- 先用七年级上册第二课《正确认识自我》跑通流程，再扩展到全书。
- 项目术语以根目录 `CONTEXT.md` 为准。

## 1. pdfs 交给 daofa-build

### 教材登记

| 字段 | 含义 |
| --- | --- |
| `source_id` | 稳定的教材来源标识 |
| `source_file` | 本地 PDF 路径 |
| `sha256` | 文件指纹，区分同名但不同内容的 PDF |
| `title` | 从教材核对的书名 |
| `edition` | 从版权页核对的版本信息；未核对时留空 |
| `page_count` | PDF 总页数 |
| `pages` | 每页记录及其教材页码映射 |

教材印刷页码与 PDF 页序分别保存。封面等没有印刷页码时用空值，不用推算出的号码代替。

### 页面记录

| 字段 | 含义 |
| --- | --- |
| `pdf_page` | 从 1 开始的 PDF 页序 |
| `textbook_page` | 页面上核对的印刷页码，字符串或空值 |
| `image_file` | 用于核对的页面图 |
| `method` | 直接提取或 OCR |
| `raw_text_file` | 保留原始识别结果 |
| `layout_file` | OCR 行、词及其页面坐标，便于核对顺序和定位 |
| `reviewed_text_file` | 核对后的文字；未核对时为空 |
| `review_status` | `extracted`、`reviewed` 或 `needs_review` |
| `reviewed_by` | 实际核对者；未核对时为空 |
| `review_notes` | 修订、疑难字、缺失或识别异常 |

已确认的核对规则：Codex 对照页面图逐页核对；无法判断的文字标记为 `needs_review`，交由用户处理。OCR 成功只产生 `extracted`，不会自动变为 `reviewed`。

支持按页处理和继续运行。继续运行前校验教材指纹，保留已经核对的文本；重新 OCR 不覆盖核对结果。

## 2. daofa-build 交给 daofa-qa

按现有逐课 Markdown 文件组织，每课包含多个知识点；知识点使用稳定编号，索引用编号和文件锚点定位。

| 字段 | 含义 |
| --- | --- |
| `id` | 在知识库内唯一的知识点编号 |
| `title` | 知识点名称 |
| `grade`、`volume`、`unit`、`lesson`、`section` | 教材位置 |
| `kind` | 概念、原因、意义、做法等 |
| `content` | 教材支持的整理表达 |
| `source_refs` | 一个或多个教材来源记录 |
| `clues` | 有助于检索的材料题眼 |
| `question_patterns` | 适用问法 |
| `status` | `draft` 或 `verified` |

每项 `source_refs` 保存 `source_id`、教材文件指纹、`pdf_page`、`textbook_page`，并指向核对文本。跨页知识点逐页列出来源。

只有核对完成且能支持知识点表达的来源才能使知识点进入 `verified`。一页包含多个观点时，来源同时注明相关段落或短文本定位提示。整理表达与直接引文区分保存；答题提示不标成教材原话。

题眼索引的每条记录包含题眼、适用问法、知识点编号、文件锚点。索引由有效知识点生成；题眼只是检索线索，作答前仍须阅读正文和来源。

## 3. daofa-qa 的证据与输出

1. 识别题目的设问和材料题眼。
2. 用题眼索引寻找候选知识点，必要时搜索知识库正文。
3. 阅读候选知识点正文，检查核对状态及其对当前题目的适用性。
4. 将每个采分点对应到知识点编号，再组织“教材观点 + 材料说明”。
5. 根据现有默认、考试、讲题模式呈现答案。

`draft`、占位文件和未核对文本不作为确定的教材依据。证据不足时输出“当前知识库依据不足”。考试模式保持精炼；讲题模式呈现题眼到知识点的映射及来源。

## 4. 第二课验收样例

已对照目录与页面图核对：第二课教材第 9–15 页对应 PDF 第 17–23 页；“认识自己”为教材第 9–11 页，“做更好的自己”为第 12–15 页。第三课首页为教材第 16 页、PDF 第 24 页。本段偏移经教材第 9、12、15、16 页页脚确认；其他章节仍须核对自己的页码映射。

本机 Windows PowerShell 5.1 能调用系统 WinRT 简体中文 OCR，已成功识别 PDF 第 17 页并返回文字和词框。试识别发现汉字间多余空格、阅读顺序错误及页眉误识，后续实现需保留坐标，并对照页面图整理核对文本。

使用现有示例题：

> 进入初中后，小明觉得自己什么都不如别人，因此越来越自卑。请结合教材知识分析小明应该怎样正确认识自己。

验收观察完整输入输出，不预先凭记忆写定答案：

- 指定第二课页面后，能得到页面图、原始文字、核对文字和双页码记录。
- 第二课知识点均能追溯到核对文本和教材页面。
- 该材料题能检索到适用知识点，每项答案要点都有来源支持。
- 同题的考试模式和讲题模式依据一致，详略不同。
- 缺少教材、未核对或知识不足时给出明确状态，避免补出没有证据的教材观点。
- 重复运行保留核对修订；换成同名但不同内容的 PDF 时识别来源变化。
