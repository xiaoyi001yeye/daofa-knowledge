# 教材页面处理

从仓库根目录操作。命令和环境要求见 [处理说明](../../../docs/pipeline-usage.md)，字段见 [交接格式](../../../docs/data-contract.md)。

1. 确认教材文件和用户指定范围；从目录、标题和页脚核对 PDF 页序与教材页码。其他章节的偏移不能自动套用。
2. 运行 `scripts/pdf_pages.py prepare`。页面图、原始文本、OCR 行/词坐标和 manifest 保存在本地 `sources/` 工作目录。
3. 对照每个页面图检查正文、标题、相关栏目和页脚。OCR 文字顺序可能错误、汉字间带空格、标点遗漏；从图像修订，保留原始识别结果。核对文本按阅读顺序区分正文、活动、案例和页脚。
4. 把修订文字保存为候选文本，调用 `review` 记录实际核对者、教材页码和修订说明。无法判断的部分明确标注并使用 `--needs-review`；向用户说明具体页码及疑难文字。
5. 完成指定范围后检查 manifest；只有 `reviewed` 页面可交给知识提炼。提交范围、双页码、已核对页数和未解决事项。

提取成功只代表 `extracted`。`review` 命令记录核对决定，不替代对图像的检查。重新运行保留已有核对与疑难记录；来源指纹变化时使用新的工作目录。

第一版扫描 OCR 使用 Windows PowerShell 5.1 与系统简体中文 OCR。环境缺少能力时按错误提示处理，已有资料继续保留。教材扫描件、页面图和完整转录保持本地保存。
