# 道法知识库构建

从仓库根目录操作。先读 [知识点输入格式与命令](../../../docs/pipeline-usage.md)，涉及字段时读 [交接格式](../../../docs/data-contract.md)。

1. 检查指定课次的 manifest、核对文本和页码；使用 `reviewed` 页面。发现疑难、缺页或来源变化时，保留草稿并返回具体问题。
2. 从完整课次提取概念、原因、意义和做法，保持教材用语和限制条件。活动问题与案例服务于知识说明，不把活动提问本身当作教材结论。
3. 将每个独立知识点组织为卡片输入：稳定编号、标题、栏目、类型、内容、题眼、问法，以及每个依据页面和短定位文字。新增编号不复用旧编号，修订同一知识点保留编号。
4. 知识内容是教材支持的整理表达，适合初中生学习与书写。直接引文只取必要短句并明确标识；答题提示和易错提醒只在教材能支持时加入。
5. 调用 `scripts/knowledge.py compile` 校验来源并生成逐课 Markdown、公开来源登记和题眼索引。跨页结论列出全部依据页面。
6. 用课内材料题验收检索及答案依据；调用 `build --manifest` 检查真实资料。目录中明确列出已经支持和仍为空缺的课次。

语义核对由 Codex 完成：检查定位文字与教材观点是否能支持卡片表达。脚本检查来源身份、核对状态、文字指纹和定位文字，不会判断推理是否成立。

知识不足时明确说“当前知识库依据不足”，不要用记忆补全。共享内容包含结构化知识、短定位文字和页码记录；PDF、页面图及完整 OCR/核对转录留在本地 `sources/`。
