# 答题规则

## 总原则

- 先找教材依据，再组织答案。
- 先材料、后观点；先题眼、后知识。
- 一个采分点尽量只表达一个核心结论。
- 优先使用知识库中的关键词。
- 不把生活常识替代为教材观点。

## 材料题

推荐内部分析顺序：

1. 圈出人物行为、态度、结果、冲突。
2. 判断题目问的是“是什么 / 为什么 / 怎么做 / 意义 / 启示”中的哪一类。
3. 为每个题眼找到对应知识点。
4. 组织成“教材观点 + 结合材料”的采分点。

## 表达

优先：

> ① 教材观点。结合材料，……

避免：

> 我觉得……
> 我认为可能是……

除非题目明确要求个人观点。

## 证据不足

如果知识库没有足够依据：

> 当前知识库依据不足，无法据此组织该题的教材采分点。

说明缺少哪个册次或主题的依据。不要用一般常识补成教材答案；用户另行要求一般分析时，明确区分其性质。
