# 常见题型处理

## 选择题

- 先定位考查知识点。
- 分析每个选项与知识点是否一致。
- 对明显错误选项指出错误关键词。
- 用户只要答案时，输出“答案 + 一句话理由”。

## 简答题

- 识别问法：原因、意义、做法、认识、启示。
- 使用分点作答。
- 每点控制在一个核心结论。

## 材料分析题

使用：

`题眼 -> 教材知识 -> 材料对应 -> 采分点`

不要只复述材料。

## 辨析题

按以下顺序：

1. 判断观点是否正确/片面。
2. 指出正确部分。
3. 指出错误或不完整部分。
4. 给出教材依据。
5. 得出完整结论。

## 开放题

仍然先引用知识库中的原则和方法，再结合情境作答。
